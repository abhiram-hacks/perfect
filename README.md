# Playwright TypeScript Automation Framework

End-to-end automation test suite built using [Playwright](https://playwright.dev/) with TypeScript, implementing the Page Object Model (POM) design pattern.

## Tech Stack
- Playwright Test
- TypeScript
- Node.js

## Project Structure
- `pages/` - Page Object Model classes and locators
- `tests/` - Test specs and scenarios
- `playwright.config.ts` - Playwright runner configuration

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm

### Installation
```bash
npm install
npx playwright install
